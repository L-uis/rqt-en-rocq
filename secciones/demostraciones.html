Imágenes

Modelaremos un pixel como un booleano, donde true y false actúan como simuladores de color.

Definition pixel := bool.

Definimos una imagen como una función dependiente que es capaz de acotar sus coordenadas para garantizar sus proporciones.

La función toma dos números naturales, que simulan ser coordenadas dentro de un plano cartesiano de dos dimensiones, y exige la prueba de que dichas coordenadas son, a lo más, 2n - 1 , asegurando que la imagen tiene un tamaño de 2n × 2n . Cuando la función se evalúa: si las demostraciones son válidas, se obtiene el pixel correspondiente a la coordenada especificada.

Definition imagen (n : nat) := forall (x y : nat), x < 2^n -> y < 2^n -> pixel.
Límites de coordenadas.

Para indicar qué valores pueden tomar las coordenadas dada la proporción de una imagen, probaremos que se cumplen las siguientes propiedades.

Lema de extensión para coordenadas.

Si una coordenada está dentro de un cuadrante (x < 2n ), entonces está dentro de la imagen completa (x < 2n+1 ).

Lemma xy_in_img : forall v n, v < 2^n -> v < 2^(S n).
▶ Demostración
 Proof. intros. simpl. lia. Qed.
Lema de Traslación.

Si trasladamos una coordenada sumándole 2n , la coordenada resultante tiene un límite que se mantiene dentro de la imagen completa (v + 2n < 2n+1 ).

Lemma xy_in_img_translacion : forall v n, v < 2^n -> v + 2^n < 2^(S n).
▶ Demostración
 Proof. intros. simpl. lia. Qed.
Cuadrantes

Para la definición de los cuadrantes, calculamos la traslación necesaria a partir de las coordenadas x, y originales; para ello consideramos la proporción de la imagen 2n+1 , por lo que las propiedades que exigimos que se cumplan en la definición son:

  • Hx: x < 2n ,
  • Hy: y < 2n .
Cuadrante NW

Representado por las coordenadas:

  • x que varía de 0 a 2n - 1 .
  • y que varía de 2n hasta 2n+1 - 1 .
Definition cuadrante_NW {n : nat} (img : imagen (S n)) : imagen n := fun x y Hx Hy => img x (y + 2^n) (xy_in_img x n Hx) (xy_in_img_translacion y n Hy).
Cuadrante NE

Representado por las coordenadas:

  • x que varía de 2n hasta 2n+1 - 1 .
  • y que varía de 2n hasta 2n+1 - 1 .
Definition cuadrante_NE {n : nat} (img : imagen (S n)) : imagen n := fun x y Hx Hy => img (x + 2^n) (y + 2^n) (xy_in_img_translacion x n Hx) (xy_in_img_translacion y n Hy).
Cuadrante SW

Representado por las coordenadas x, y que varían de 0 a 2n - 1 .

Definition cuadrante_SW {n : nat} (img : imagen (S n)) : imagen n := fun x y Hx Hy => img x y (xy_in_img x n Hx) (xy_in_img y n Hy).
Cuadrante SE

Representado por las coordenadas:

  • x que varía de 2n hasta 2n+1 - 1 .
  • y que varía de 0 a 2n - 1 .
Definition cuadrante_SE {n : nat} (img : imagen (S n)) : imagen n := fun x y Hx Hy => img (x + 2^n) y (xy_in_img_translacion x n Hx) (xy_in_img y n Hy).
Mapeo de coordenadas y ensamblaje de cuadrantes

Para crear una imagen de tamaño 2n+1 a partir de 4 cuadrantes de tamaño 2n , es necesario encontrar en qué cuadrante se localizarán las coordenadas de la imagen que estamos creando/ensamblando; a dichas coordenadas les llamaremos coordenadas globales.

Consideremos, sin pérdida de generalidad, que el valor de la coordenada global x se encuentra en la segunda mitad de la imagen (hacia cualquier dirección). Sabemos entonces que x ≥ 2n , por lo que debemos buscar el pixel que la representa en los cuadrantes derechos (SE, NE).

Sin embargo, todos los cuadrantes se definen con coordenadas cuyo valor varía de 0 hasta 2n - 1 .

Por lo tanto, la operación necesaria para encontrar la coordenada en el cuadrante correspondiente resulta de sustraer 2n unidades a la coordenada global x.

Lo cual indica que necesitamos una verificación de que la coordenada que se asignará (cuyo valor es x - 2n ), no excederá los límites del cuadrante.

Para ello demostramos el Lema de localización :

Lemma localiza_xy_desde_2n : forall v n, ~ (v < 2^n) -> v < 2^(S n) -> v - 2^n < 2^n.
▶ Demostración
 Proof. simpl in H0. lia. Qed.
La función de ensamblaje.

A partir de 4 sub-imágenes de tamaño 2n , devuelve una imagen cuyas proporciones son 2n+1 .

Definition ensamblar {n : nat} (nw ne sw se : imagen n) : imagen (S n) := fun x y Hx Hy => match lt_dec x (2^n), lt_dec y (2^n) with | left Hx_lt, right Hy_ge => nw x (y - 2^n) Hx_lt (localiza_xy_desde_2n y n Hy_ge Hy) | right Hx_ge, right Hy_ge => ne (x - 2^n) (y - 2^n) (localiza_xy_desde_2n x n Hx_ge Hx) (localiza_xy_desde_2n y n Hy_ge Hy) | left Hx_lt, left Hy_lt => sw x y Hx_lt Hy_lt | right Hx_ge, left Hy_lt => se (x - 2^n) y (localiza_xy_desde_2n x n Hx_ge Hx) Hy_lt end.
Lema de Mapeo de Pixeles

Dos llamadas a una imagen son iguales si sus coordenadas son iguales (x1 = x2, y1 = y2), incluso si las demostraciones que se otorgan para cada valor son distintas.

Lemma pixel_eq : forall n (img : imagen n) x1 y1 x2 y2 (Hx1 : x1 < 2^n) (Hy1 : y1 < 2^n) (Hx2 : x2 < 2^n) (Hy2 : y2 < 2^n), x1 = x2 -> y1 = y2 -> img x1 y1 Hx1 Hy1 = img x2 y2 Hx2 Hy2.
▶ Demostración
 Proof. intros. subst. f_equal. -apply le_unique. -apply le_unique. Qed.
Teorema de Ensamblaje

Dividir y ensamblar la imagen preserva su estructura.

Theorem teorema_ensamblaje : forall {n} (img : imagen (S n)), ensamblar (cuadrante_NW img) (cuadrante_NE img) (cuadrante_SW img) (cuadrante_SE img) = img.
▶ Demostración
 Proof. intros. Bajo el concepto de extensionalidad funcional, sabemos que las funciones son iguales si arrojan el mismo resultado al ser evaluadas con los mismos argumentos. extensionality x. extensionality y. extensionality Hx. extensionality Hy. unfold ensamblar. Procedemos por casos según los valores de las coordenadas x, y: destruct (lt_dec x (2^n)) as [Hx_lt | Hx_ge]; destruct (lt_dec y (2^n)) as [Hy_lt | Hy_ge]. Caso 1: SW (x < 2n, y < 2n).
Las coordenadas globales corresponden exactamente a las locales. [ensamblar] utiliza los valores de entrada para buscar el pixel sin realizar modificaciones, por lo cual es inmediato. - unfold cuadrante_SW. apply pixel_eq. + reflexivity.(*x = x*) + reflexivity.(*y = y*) Caso 2: NW(x < 2n, y ≥ 2n).
Para la coordenada [y], la función [ensamblar] obtiene el pixel a devolver restando 2n a [y]. Por lo que, el cuadrante NW proyecta la coordenada (y - 2n) + 2n = y. Como y ≥ 2n, la igualdad es correcta. Además, [x] mantiene intacto su valor de entrada. - unfold cuadrante_NW. apply pixel_eq. + reflexivity. (* x = x *) + lia. (* (y - 2^n) + 2^n = y *) Caso 3: SE (x ≥ 2n, y < 2n). Análogamente, para la coordenada [x], la función [ensamblar] obtiene la coordenada restando 2n a [x]. Por lo que, [cuadrante_SE] proyecta la coordenada (x - 2n) + 2n = x. Como x ≥ 2n, la igualdad es correcta. Además, [y] mantiene intacto su valor de entrada. - unfold cuadrante_SE. apply pixel_eq. lia. Caso 4: NE (x ≥ 2n, y ≥ 2n).
[x] tiene el mismo comportamiento que en el caso 3, mientras que [y] tiene el mismo comportamiento que en el caso 2, por lo cual las coordenadas son:
- (x - 2n) + 2n = x
- (y - 2n) + 2n = y - unfold cuadrante_NE. apply pixel_eq. lia.
Region Quadtree
Inductive region_qt : Type := Cualquier región homogénea es una hoja en el árbol; agregamos como argumento el pixel dentro de la imagen para recuperar el valor del color homogéneo que representa la hoja. | Leaf : pixel -> region_qt Si la imagen es heterogénea, se define recursivamente sobre 4 subárboles que corresponden de manera ordenada a los cuadrantes: NW, NE, SW y SE. | Node : region_qt -> region_qt -> region_qt -> region_qt -> region_qt.
Construcción RQT

Es inmediato notar que la construcción de un Region Quadtree (RQT) tiene la necesidad de determinar cuándo una sección de color está compuesta por un color único, y cuándo se compone por una variación de colores.

La validación necesaria se realiza mediante la función auxiliar es_homogenea, la cual se desenvuelve de manera recursiva sobre el exponente n que dicta las proporciones de la imagen. Cuando la imagen es de un solo color devuelve Some color_img, en otro caso devuelve None.

Fixpoint es_homogenea (n : nat) : imagen n -> option pixel := match n with | 0 => fun img => Some (img 0 0 (Nat.lt_0_1) (Nat.lt_0_1)) | S n' => fun img => match es_homogenea n' (cuadrante_NW img), es_homogenea n' (cuadrante_NE img), es_homogenea n' (cuadrante_SW img), es_homogenea n' (cuadrante_SE img) with | Some c_nw, Some c_ne, Some c_sw, Some c_se => match c_nw, c_ne, c_sw, c_se with | true, true, true, true => Some true | false, false, false, false => Some false | _, _, _, _ => None end | _, _, _, _ => None end end.

Resulta indispensable demostrar que la función es_homogenea se comporta como debe. Por ello, enunciamos el Teorema: es_homogenea_correcta.

La demostración de este teorema prueba que la función es_homogenea determina correctamente que si una región es coloreada por un único color, entonces cualquier coordenada (x, y) dentro de esa región devuelve exactamente el color identificado.

Theorem es_homogenea_correcta : forall n img color, es_homogenea n img = Some color -> (forall x y Hx Hy, img x y Hx Hy = color).
▶ Demostración
 Proof. induction n as [| n' IHn'].. Caso Base (n = 0): Píxel (Imagen de 20 × 20) intros. simpl in H. injection H as H_color. rewrite <- H_color. simpl in Hx; simpl in Hy. apply pixel_eq; lia. Paso Inductivo (n > 0 ): La imagen puede ser dividida en 4 cuadrantes.
Procedemos por casos sobre los resultados favorables. intros. simpl in H. destruct (es_homogenea n' (cuadrante_NW img)) as [c_nw |] eqn:H_nw; try discriminate; destruct (es_homogenea n' (cuadrante_NE img)) as [c_ne |] eqn:H_ne; try discriminate; destruct (es_homogenea n' (cuadrante_SW img)) as [c_sw |] eqn:H_sw; try discriminate; destruct (es_homogenea n' (cuadrante_SE img)) as [c_se |] eqn:H_se; try discriminate. destruct c_nw, c_ne, c_sw, c_se; try discriminate. Caso [true]:
Los 4 cuadrantes están representados por el color correspondiente al valor [true]. injection H as H_color. subst color. destruct (lt_dec x (2^n')) as [Hx_lt | Hx_ge]; destruct (lt_dec y (2^n')) as [Hy_lt | Hy_ge]. Pixel en el cuadrante SW * assert (H_pixel : cuadrante_SW img x y Hx_lt Hy_lt = true). { apply IHn'; exact H_sw. } unfold cuadrante_SW in H_pixel. rewrite <- H_pixel. apply pixel_eq; lia. Pixel en el cuadrante SE assert (H_pixel : cuadrante_SE img (x - 2^n') y (localiza_xy_desde_2n x n' Hx_ge Hx) Hy_lt = true). { apply IHn'; exact H_se. } unfold cuadrante_SE in H_pixel. rewrite <- H_pixel. apply pixel_eq; lia. Pixel en el cuadrante NE assert (H_pixel : cuadrante_NE img (x - 2^n') (y - 2^n') (localiza_xy_desde_2n x n' Hx_ge Hx) (localiza_xy_desde_2n y n' Hy_ge Hy) = true). { apply IHn'; exact H_ne. } unfold cuadrante_NE in H_pixel. rewrite <- H_pixel. apply pixel_eq; lia. Caso [false]:
Los 4 cuadrantes están representados por el color correspondiente al valor [false]. + injection H as H_color. subst color. destruct (lt_dec x (2^n')) as [Hx_lt | Hx_ge]; destruct (lt_dec y (2^n')) as [Hy_lt | Hy_ge]. Pixel en el cuadrante SW * assert (H_pixel : cuadrante_SW img x y Hx_lt Hy_lt = false). { apply IHn'; exact H_sw. } unfold cuadrante_SW in H_pixel. rewrite <- H_pixel. apply pixel_eq; lia. Pixel en el cuadrante NW * assert (H_pixel : cuadrante_NW img x (y - 2^n') Hx_lt (localiza_xy_desde_2n y n' Hy_ge Hy) = false). { apply IHn'; exact H_nw. } unfold cuadrante_NW in H_pixel. rewrite <- H_pixel. apply pixel_eq; lia. Pixel en el cuadrante SE * assert (H_pixel : cuadrante_SE img (x - 2^n') y (localiza_xy_desde_2n x n' Hx_ge Hx) Hy_lt = false). { apply IHn'; exact H_se. } unfold cuadrante_SE in H_pixel. rewrite <- H_pixel. apply pixel_eq; lia. Pixel en el cuadrante NE * assert (H_pixel : cuadrante_NE img (x - 2^n') (y - 2^n') (localiza_xy_desde_2n x n' Hx_ge Hx) (localiza_xy_desde_2n y n' Hy_ge Hy) = false). { apply IHn'; exact H_ne. } unfold cuadrante_NE in H_pixel. rewrite <- H_pixel. apply pixel_eq; lia. Qed.

Tras verificar que la función es_homogenea se comporta correctamente, podemos definir la función encargada de la construcción de un region_qt mediante su uso.

Fixpoint construye_region_qt (n : nat) : imagen n -> region_qt := match n with | 0 => fun img => Leaf (img 0 0 (Nat.lt_0_1) (Nat.lt_0_1)) | S n' => fun img => match es_homogenea (S n') img with | Some color => Leaf color | None => Node (construye_region_qt n' (cuadrante_NW img)) (construye_region_qt n' (cuadrante_NE img)) (construye_region_qt n' (cuadrante_SW img)) (construye_region_qt n' (cuadrante_SE img)) end end.
Recuperación de la imagen

Dado que nuestra definición de imagen devuelve una función. Para recuperar el contenido de las hojas es necesario contar con una función constante que, sin importar las coordenadas especificadas, devuelva el color especificado de la región.

Definimos dicha función como sigue:

Definition generar_imagen_homogenea (n : nat) (color : pixel) : imagen n := fun x y Hx Hy => color.

La funcion servirá para realizar el recorrido por profundidad que es capaz de recuperar de manera ordenada la imagen almacenada en el region_qt:

Fixpoint recorre_region_qt (n : nat) (qt : region_qt) : imagen n := match qt with | Leaf color => generar_imagen_homogenea n color | Node nw ne sw se => match n with Para mantener la totalidad de la función, devolvemos el color representado por false, sin embargo, sabemos que este caso no sucede, pues un pixel no se puede dividir | 0 => generar_imagen_homogenea 0 false | S n' => ensamblar (recorre_region_qt n' nw) (recorre_region_qt n' ne) (recorre_region_qt n' sw) (recorre_region_qt n' se) end end.
Nota: Opacidad de la función

La siguiente instruccion impide que Rocq expanda la definición de la función es_homogenea con la táctica simpl hasta que se le indique lo contrario.

Esto es necesario porque la expansión de la definición provoca que las pruebas que utilizan su aplicación se alarguen intentando demostrar cada caso para el cual está definida es_homogenea. Esto resulta innecesario tras haber demostrado la correctitud de la función en el Teorema es_homogenea_correcta.

De ello sabemos que la aplicación de la función evaluará sus argumentos de la manera esperada para cualquier valor de entrada que cumpla las precondiciones correspondientes.

EL uso de Opaque no debilita las demostraciones en las que la función sea requerida a partir de este momento. Al haber demostrado con anterioridad su correctitud, se garantiza que las siguientes demostraciones dependen únicamente de la lógica y geometría correspondientes al enunciado que se desea probar, y no a la función es_homogenea.

Opaque es_homogenea.
Teorema de Identidad

El siguiente teorema concluye la formalización de la estructura tras verificar que la composición de funciones: construye_region_qt seguida de recorre_region_qt resulta en la función identidad.

Este resultado garantiza que no ocurre pérdida de información al realizar el proceso de almacenamiento y recuperación de cualquier imagen.

Theorem identidad_region_qt : forall (n : nat) (img : imagen n), recorre_region_qt n (construye_region_qt n img) = img.
▶ Demostración
 Proof. intros. induction n as [| n' IHn']. Caso Base (n = 0): La imagen es un pixel. - simpl. extensionality x. extensionality y. extensionality Hx; simpl in Hx. extensionality Hy; simpl in Hy. unfold generar_imagen_homogenea. symmetry. apply pixel_eq. + lia. + lia. Paso Inductivo (n = S n'): La imagen puede ser dividida en cuadrantes. - simpl construye_region_qt. destruct (es_homogenea (S n') img) as [color |] eqn:Hom. Caso [Leaf]: Los cuadrantes contienen regiones homogéneas del mismo color + simpl recorre_region_qt. extensionality x; extensionality y; extensionality Hx; extensionality Hy. unfold generar_imagen_homogenea. assert (H_color : img x y Hx Hy = color). { exact (es_homogenea_correcta (S n') img color Hom x y Hx Hy). } symmetry. exact H_color. Caso [Node]: La imagen contiene variación de colores y requirió dividirse + simpl recorre_region_qt. rewrite IHn'; rewrite IHn'; rewrite IHn'; rewrite IHn'. apply teorema_ensamblaje. Qed.
Invariantes para RQT
Representación Mínima.

Ningún nodo interno se asocia como padre de 4 cuadrantes que representen el mismo color, pues de ser así las 4 regiones homogéneas del mismo color deberían haberse representado con el constructor Leaf un nivel antes.

Inductive es_minimo : region_qt -> Prop := Una hoja que representa el color de una región en el árbol es,por definición, la representación mínima de una región. | Min_Leaf : forall c, es_minimo (Leaf c) Un nodo es la representación mínima de una región heterogénea si se cumplen:
1) Sus 4 subárboles son mínimos.
2) No ocurre que exista un color c tal que la construcción de los 4 subárboles esté dada por Leaf c. | Min_Node : forall nw ne sw se, es_minimo nw -> es_minimo ne -> es_minimo sw -> es_minimo se -> ~ (exists c, nw = Leaf c /\ ne = Leaf c /\ sw = Leaf c /\ se = Leaf c) -> es_minimo (Node nw ne sw se).

Antes de abordar el teorema principal para la demostración de esta invariante, requerimos demostrar dos propiedades sobre el comportamiento de nuestras funciones.

EL primer resultado se establece con el lema construye_leaf_homogenea, el cual establece que si el algoritmo de construcción para region_qt devuelve una función para construir Leaf c, entonces la función es_homogenea identificó la región como homogénea devolviendo Some c.

Lemma construye_leaf_homogenea : forall n img c, construye_region_qt n img = Leaf c -> es_homogenea n img = Some c.
▶ Demostración
 Proof. intros n img c. destruct n as [| n']. Caso Base (n = 0): La imagen representa un pixel. - intros H. simpl in H. injection H as H_color. rewrite <- H_color. reflexivity. Paso Inductivo (n = S n'): La imagen se puede dividir en 4 cuadrantes. - intros H. simpl in H. destruct (es_homogenea (S n') img) eqn:Hom. Caso [Some]: [es_homogenea (S n') img = Some p] + injection H as Hc. rewrite Hc. reflexivity. Caso [None]: [es_homogenea (S n') img = None]
El constructor Node jamás podrá ser definido de manera equivalente al constructor Leaf, por lo cual, el caso no tiene sentido. discriminate H. Qed.
Nota: Extensión de la definición

Para demostrar que el RQT cumple la invariante definida por el predicado es_minimo, no basta con que la función es_homogenea sea correcta, como ha ocurrido hasta ahora; necesitamos comprobar el comportamiento que ejecuta en cada caso para corroborar que una región homogénea no será representada por el constructor Node, por lo cual permitimos que la definición de es_homogenea sea visible para el siguiente lema.

Transparent es_homogenea.

El lema composicion_homogenea establece que si los cuadrantes de una imagen arrojan exactamente el mismo color, c, entonces la función es_homogenea devolverá Some c para la imagen que los contiene.

Lemma composicion_homogenea : forall n img c, es_homogenea n (cuadrante_NW img) = Some c -> es_homogenea n (cuadrante_NE img) = Some c -> es_homogenea n (cuadrante_SW img) = Some c -> es_homogenea n (cuadrante_SE img) = Some c -> es_homogenea (S n) img = Some c.
▶ Demostración
 Proof. intros n img c Hnw Hne Hsw Hse. simpl. rewrite Hnw; rewrite Hne; rewrite Hsw; rewrite Hse. destruct c. + reflexivity. + reflexivity. Qed.
Nota: Ocultar la definición

Tras haber demostrado el lema anterior, y por la misma razón por la cual prohibimos a simpl desarrollar la definición de la función es_homogenea, volvemos a ocultarla.

Opaque es_homogenea.
Teorema: Construcción Mínima

Para cualquier imagen definida correctamente, el algoritmo construye_region_qt siempre genera el árbol representativo minimizado.

Theorem construccion_es_minima : forall n img, es_minimo (construye_region_qt n img).
▶ Demostración
 Proof. intros n. induction n as [| n' IHn']. Caso Base (n = 0 ): La imagen es un píxel. - intros img. simpl construye_region_qt. apply Min_Leaf. Paso Inductivo (n = S n'): La imagen se puede dividir en 4 cuadrantes. - intros img. simpl construye_region_qt. destruct (es_homogenea (S n') img) as [color |] eqn:Hom. Caso [Some]:
Los cuadrantes contienen regiones homogéneas del mismo color y, por tanto, se representan en una hoja, que por definición cumple ser la representación mínima de la región. + apply Min_Leaf. Caso [None]:
La imagen se compone de 4 cuadrantes con diferentes colores, por lo que se representa con el constructor [Node]. + apply Min_Node. * apply IHn'. (*NW*) * apply IHn'. (*NE*) * apply IHn'. (*Sw*) * apply IHn'. (*SE*) Por contradicción, asumamos que los subárboles representan una región homogénea del mismo color. * intros [c [Hnw [Hne [Hsw Hse]]]]. apply construye_leaf_homogenea in Hnw; apply construye_leaf_homogenea in Hne; apply construye_leaf_homogenea in Hsw; apply construye_leaf_homogenea in Hse. assert (Contra : es_homogenea (S n') img = Some c). { exact (composicion_homogenea n' img c Hnw Hne Hsw Hse). } rewrite Hom in Contra. discriminate Contra. Qed.
Altura Máxima.

Para acotar la altura de los árboles construidos mediante la función construye_region_qt, necesitamos establecer los criterios para calcular la altura de un RQT. Para ello, seguimos la definición convencional donde la altura se calcula respecto al camino más largo de la raíz a las hojas:

Fixpoint altura_qt (qt : region_qt) : nat := match qt with | Leaf _ => 0 | Node nw ne sw se => S (Nat.max (Nat.max (altura_qt nw) (altura_qt ne)) (Nat.max (altura_qt sw) (altura_qt se))) end.
Teorema: Altura máxima

Para cualquier imagen con proporciones 2n × 2n , la altura máxima de un RQT generado por construye_region_qt es a lo más, log4(num_pixeles) = n .

Theorem altura_max : forall n img, altura_qt (construye_region_qt n img) <= n.
▶ Demostración
 Proof. intros n. induction n as [| n' IHn']. Caso Base (n = 0): La imagen es un píxel. - intros img. simpl construye_region_qt. simpl altura_qt. lia.
