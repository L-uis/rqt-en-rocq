Estructura del Quadtree

La estructura de datos se divide principalmente en dos componentes lógicos que permiten la representación espacial.

Nodos Hoja (Leaves)

Representan las regiones que son completamente homogéneas, es decir, donde todos los elementos comparten la misma propiedad.

Nodos Internos (Branches)

Representan áreas heterogéneas que deben ser subdivididas iterativamente en cuatro cuadrantes de menor tamaño.

Para construir la prueba, primero necesitamos definir los casos base.

Definición: Nodo Homogéneo
Un nodo se considera homogéneo si todos los píxeles en su región correspondiente comparten exactamente el mismo valor o color.

Demostración: construye_leaf_homogenea

A continuación se muestra el código de la prueba formal:

Lemma construye_leaf_homogenea : ∀ n img c, construye_region_qt n img = Leaf c → es_homogenea n img = Some c. Proof. intros n img c. destruct n as [| n']. - intros H. simpl in H. injection H as H_color. rewrite <- H_color. reflexivity.
